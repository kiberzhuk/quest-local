# Изменения

## 0.5.0

- Проверенные кнопки открытия обычных Android-настроек «Для разработчиков»
  и «Сеть и интернет» через Wi-Fi ADB; без установки APK и без переключения настроек.
- Проверка Activity RESUMED + visible=true вместо успеха только по ответу запуска.
- Сообщение об активном Guardian без отключения границы безопасности.
- Повторное обнаружение динамического порта на том же IP; ожидание отдельного
  порта подключения до двух минут после сопряжения, с подсказкой о разрешении сети.
- Разделены Android Developer Options, прямой BLE-статус и статус аккаунта Meta.
- Исправлено поле app_id для экспериментального BLE-запуска Settings. На проверенной
  прошивке этот путь всё равно отказал; рабочие кнопки используют Android Intent через ADB.
- Добавлены тесты, Windows CI, рекомендации по безопасности, исключения Git
  и экспорт архива только с исходниками.
- Удалены из интерфейса неподтверждённые экспериментальные команды и отдельная
  диагностическая кнопка. Старый тестовый APK и его сборка не входят в публикацию.

## 0.4.1

- Включение двух фиксированных Android-настроек отладки с повторным чтением.
- Раздельное отображение BLE-статусов 6002 и 8001.
- Проверены установка/запуск тестового APK и запись файла в Movies.

## 0.4.0

- Wi-Fi ADB через авторизованный BLE Companion API.
- Проверяемое удержание бодрствования и возврат к физическому датчику.
