# История изменений

## 0.5.0

- Добавлены кнопки «Открыть „Для разработчиков“» и «Открыть „Сеть и интернет“».
  Они используют стандартные Android Intent через Wi-Fi ADB.
- После запуска проверяются состояние Activity и видимость окна.
  Если мешает Guardian, программа предлагает подтвердить границу в шлеме.
- Ожидание порта ADB после сопряжения увеличено до двух минут.
  При повторном подключении порт ищется по IP ранее выбранного шлема.
- Из интерфейса убраны неработающие экспериментальные команды.
- Добавлены экспорт исходников и тесты GitHub Actions для Windows.

## 0.4.1

- Добавлено включение Android-настроек разработчика и USB-отладки
  с повторным чтением результата.
- Прямой BLE-статус отладки и общий статус шлема выводятся отдельно.
- На Quest проверены установка тестового APK и запись файла в Movies.

## 0.4.0

- Добавлено сопряжение Wi-Fi ADB через Bluetooth Companion API.
- Добавлены удержание бодрствования снятого шлема и возврат обычного сна.
