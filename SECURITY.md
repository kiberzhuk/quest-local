# Безопасность

Используйте утилиту только со своим шлемом и в доверенной локальной сети.
ADB предоставляет авторизованному ПК широкие возможности доступа к устройству.
После работы отключайте ненужную беспроводную отладку в настройках шлема.

Не публикуйте `oc_www_at`, `device_secret`, cookies, содержимое профиля браузера,
коды сопряжения, `adbkey`, файлы ключей и необработанные диагностические дампы.
IP, серийные номера, сведения об аккаунте и имена приложений тоже могут быть
персональными данными. Просмотрите журнал перед отправкой в issue.

Расширение Vivaldi передаёт токен только после явного нажатия в локальной вкладке.
Программа держит токен/секрет в памяти; браузер независимо сохраняет обычную
сессию пользователя. Защищённое стирание памяти не гарантируется.

BLE проверяет подпись присланным сертификатом, но не проверяет цепочку Meta
или заранее доверенный отпечаток. Выбирайте правильное устройство рядом с ПК.
Не считайте это криптографически полной проверкой личности шлема.

Удержание бодрствования повышает нагрев и расход энергии. Не оставляйте шлем
без присмотра; используйте «Вернуть обычный сон» после работы.

При обнаружении утечки сначала отзовите затронутую сессию/авторизацию и не
выкладывайте секрет в публичный issue. Для приватного сообщения об уязвимости
используйте GitHub Private vulnerability reporting, если владелец репозитория
его включил; иначе запросите приватный канал без публикации деталей.
