# Quest Local

Программа для Windows, которая подключает Quest 3 к компьютеру по Wi-Fi
и открывает в шлеме настройки Android «Для разработчиков» и «Сеть и интернет».
Устанавливать приложения на шлем для этого не нужно.

Для входа в аккаунт Meta используется браузер [Vivaldi](https://vivaldi.com/).
Интерфейс программы на русском языке.

## Что важно знать

Кнопка «Для разработчиков» открывает меню только после подключения ADB.
ADB — это соединение, через которое компьютер отправляет команды шлему.
Сама кнопка не включает отладку и не обходит ограничения Meta.

Программа проверена на Quest 3 с прошивкой V2.10 и браузером Vivaldi.
На этом шлеме отладка уже работала, а режим разработчика Android был включён.
Работа на шлеме с изначально выключенной отладкой не проверялась.
На других моделях и прошивках результат может отличаться.

Режим разработчика в настройках Android и статус разработчика аккаунта Meta —
не одно и то же. Программа не регистрирует аккаунт разработчика Meta.
Работа по USB и подключение SideQuest по кабелю не проверялись.

## Что понадобится

- Компьютер с Windows и Bluetooth.
- [Python 3.11 или новее](https://www.python.org/downloads/windows/).
  При установке отметьте пункт **Add python.exe to PATH**.
- [Vivaldi](https://vivaldi.com/) с выполненным входом в аккаунт Meta,
  которому принадлежит шлем.
- [Android Platform-Tools для Windows](https://developer.android.com/tools/releases/platform-tools).
  Распакуйте архив так, чтобы файл `adb.exe` находился в
  `C:\Program Files\platform-tools\adb.exe`.
- Компьютер и шлем в одной домашней сети. Компьютер можно подключить кабелем
  к тому же роутеру, к которому Quest подключён по Wi-Fi.

## Первый запуск

1. На [странице релиза](https://github.com/kiberzhuk/quest-local/releases/latest)
   скачайте `QuestLocal-0.5.0-source.zip` и распакуйте его в отдельную папку.
   Не запускайте файлы прямо из архива.
2. Запустите `setup.bat` и дождитесь окончания установки. Нужен интернет.
   Этот шаг достаточно выполнить один раз.
3. Запустите `start.bat`. Откроется окно Quest Local.
4. Нажмите «Установить расширение». Откроются настройки расширений Vivaldi
   и папка `vivaldi-extension`.
5. В настройках расширений включите «Режим разработчика», нажмите
   «Загрузить распакованное расширение» и выберите папку `vivaldi-extension`.
   Здесь речь о режиме браузера, а не шлема.

В дальнейшем для запуска программы достаточно открыть `start.bat`.

## Как подключить шлем

1. В программе нажмите «Войти в Meta». В открывшейся вкладке Vivaldi нажмите
   «Использовать вход Meta». Если потребуется, войдите в свой аккаунт на сайте Meta.
   Если расширение только что установлено, обновите вкладку и повторите действие.
2. Включите Bluetooth на компьютере. Разбудите шлем, разблокируйте его
   и положите рядом.
3. Нажмите «Найти Quest», выберите свой шлем и нажмите «Подключиться».
4. Нажмите «Подключить Wi-Fi ADB» и следуйте подсказкам программы.
   Проверьте запросы внутри шлема: разрешение отладки для Wi-Fi-сети
   может появиться отдельно от запроса подключения компьютера.
5. Дождитесь подтверждения подключения. Это может занять до двух минут.
6. Нажмите «Открыть „Для разработчиков“» и посмотрите в шлем — там должно
   появиться окно настроек Android.

Повторять вход Meta перед каждой кнопкой не нужно. После закрытия и нового
запуска программы нажмите «Войти в Meta» снова. Закрывать Vivaldi не требуется.

## Другие кнопки

- **«Открыть „Сеть и интернет“»** — открывает сетевые настройки Android.
- **«Проверить ADB»** — проверяет соединение с компьютером и состояние отладки.
- **«Проверить статус»** — запрашивает сведения о шлеме по Bluetooth.
  Эти сведения могут расходиться с настройками Android. Для проверки соединения
  используйте «Проверить ADB».
- **«Включить отладку для SideQuest»** — после подтверждения пытается включить
  настройки разработчика Android и USB-отладку, затем проверяет результат.
  Это не гарантия работы SideQuest по кабелю.
- **«Не усыплять снятый шлем»** — оставляет шлем включённым после снятия.
  Он будет быстрее разряжаться и сильнее греться. Не оставляйте его без присмотра.
- **«Вернуть обычный сон»** — отменяет удержание шлема включённым.
  Нажмите эту кнопку после работы: закрытие программы само по себе сон не возвращает.

Кнопки открытия настроек сами ничего не переключают.
Программа не устанавливает игры и не копирует файлы на шлем.

## Если не получилось

- **Программа не запускается:** проверьте установку Python и повторно запустите
  `setup.bat`. После успешной установки откройте `start.bat`.
- **Не найден ADB:** проверьте, что `adb.exe` лежит по пути, указанному выше.
- **Не проходит вход Meta:** проверьте вход в Vivaldi и установку расширения.
  В этой версии программа запускает только Vivaldi.
- **Не найден шлем:** проверьте Bluetooth, разбудите Quest и поднесите его ближе.
- **Не подключается Wi-Fi ADB:** проверьте общую сеть и запросы в шлеме.
  После перезагрузки Quest может потребоваться повторное подключение.
- **Не открывается меню:** сначала нажмите «Проверить ADB». Если в шлеме открыт
  запрос настройки безопасной границы (Guardian), завершите его и попробуйте снова.

## Безопасность

Подключайте только свой шлем и используйте свою сеть. Разрешение ADB даёт
компьютеру доступ к управлению устройством. Закрытие программы это разрешение
не отзывает. Когда отладка больше не нужна, отключите её в настройках шлема.

Пароль вводится только на сайте Meta. После нажатия «Использовать вход Meta»
расширение передаёт программе данные текущего входа. Программа хранит их
в памяти и не сохраняет в файлы или журнал. Сам браузер сохраняет вход как обычно.
Не отправляйте другим людям данные аккаунта и ключи подключения.

Bluetooth-подключение не даёт полной проверки подлинности устройства.
Внимательно выбирайте свой шлем. Подробности — в [SECURITY.md](SECURITY.md).

## Для разработки

Папка `tests` содержит автоматические проверки. Для обычного запуска они не нужны.

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python app.py --smoke-test
```

Команда `python export_source.py` собирает архив исходников в папку `exports`.
Ключи, окружение Python, APK и диагностические файлы в него не включаются.

Описание Bluetooth-протокола:
[quest-ble-client](https://github.com/ptrpaws/quest-ble-client/blob/main/PROTOCOL.md).
Проект не связан с Meta.
